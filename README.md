## 📚 Curriculum & Research Focus

This repository contains an exhaustive suite of hands-on laboratory experiments, model fine-tuning pipelines, and practical assignments covering contemporary **Generative Artificial Intelligence** and **Large Language Models (LLMs)**.

---

## 🔬 Key Laboratory Highlights

### 1. GPT-2 Fine-Tuning Pipeline (`Assignment_11_GPT2_Fine_Tuning.ipynb`)
- End-to-end domain-specific fine-tuning of OpenAI's pretrained **GPT-2** language model.
- Tokenization using Byte-Pair Encoding (BPE), causal language modeling loss optimization, and temperature-controlled beam search generation.
- Evaluation using validation perplexity curves and sample qualitative synthesis.

### 2. Transformer Architectures & Multi-Head Self-Attention
- In-depth study of self-attention mechanisms, positional encodings, and query-key-value (Q-K-V) projection spaces.
- Implementation of sequence-to-sequence translation and summarization workflows.

### 3. Paraphrase Generation & Text Style Transfer (`Assignment9_GenAI_Paraphrased.ipynb`)
- Neural sequence generation techniques for paraphrasing while preserving semantic fidelity.
- Prompt engineering pipelines and conditional generation experiments.

### 4. Foundations of Generative Modeling (Assignments 1–10)
- Variational Autoencoders (VAEs), latent vector interpolation, Markov decision processes, and adversarial generation concepts.
